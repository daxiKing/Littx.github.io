# LITTX CLIENT website

A static GitHub Pages landing page for the LITTX Minecraft 1.8.9 client.

## Publish with GitHub Pages
1. Upload `index.html` and `littx-client-1.2.0.jar` to the root of your `YOUR-USERNAME.github.io` repository.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Wait for deployment and visit `https://YOUR-USERNAME.github.io/`.

The free download button points to the JAR in this repository. The premium plan is a coming-soon information panel only; no checkout or payment processing is included.

## Customize
- Edit the title, text, and pricing in `index.html`.
- Replace the JAR by uploading a new file and updating its filename in the download link.
