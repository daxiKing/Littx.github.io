Version 2.0.0 — 1.8.9 Build

A release/version and packaging update. No gameplay or GUI source changes were made in this build; the 1.3.0 feature set and all 53 self-checks were retained.

  • Release version updated from 1.3.0 to 2.0.0.
  • Artifact renamed to LITTX-CLIENT-2.0.0.jar.
  • Updated Raven.releaseVersion, Forge @Mod version, version resource (2-0-0) and mcmod.info.
  • Clean build passed; expected GUI/module classes and loader metadata were present.
  • Artifact size: 8,219,137 bytes.
  • SHA-256: 9D371CFB6AC4F0AEAA8562FD5F7A461F4980484C044C186069383934F09D53FF.
Verification note: Minecraft itself was not launched for this release. Live rendering, keybinds, macros, module behaviour and HUD placement were not verified.
1.3.0·FULL EDITION FOUNDATION

LITTX CLIENT 2.0 FULL EDITION

The full-edition feature set carried into the 2.0.0 build.

GUI 2.0 & customization

  • First-open chooser with New GUI, Old GUI and Classic GUI; choice is persisted.
  • New GUI: seven categories — Automation, Fun, General, Visuals, Movement, Utility and Combat — with per-column scrolling and responsive wrapping.
  • Configs button, centered module search, theme and GUI-style controls, hover descriptions, right-click toggles and left-click module browser access.
  • Module browser preselection, recently opened modules and shortcuts to theme/GUI settings, HUD editor, integrity dashboard and macro editor.
  • Configs screen with load, delete, NEW, SAVE, REFRESH and CLOSE actions using validated paths.
  • Anime, Dark, Light, System, Purple and Kawai presets; preset/custom/rainbow accent modes, custom color, background opacity, animation speed, particle density and logo/player/particles/watermark toggles.

New modules

  • Combat & player info: HitStatistics, ComboCounter, TargetHUD, AttackCooldownDisplay and CombatSessionTracker.
  • Movement: DirectionHUD, SpeedDisplay, JumpStatistics, MovementRecorder, Jesus, Speed, AutoWalk, AutoSwim, AirJump and Spider.
  • Render & world: WorldTimeDisplay, CoordinatesHUD, ArmorStatus, PotionStatus and FPSGraph.
  • Client & configuration: ModuleProfiles, AdvancedNotifications, ConfigurationBackup, ServerRuleProfiles and IntegrityMode.
  • Utility & automation: AutoMLG, AutoTorch, AutoDoor and AutoFish.
  • Macros: AnchorMacro and CrystalMacro are configurable use/place-and-break sequences; they do not reproduce mechanics absent from Minecraft 1.8.9.

Corrections & diagnostics

  • TriggerBot target validation, visibility/friend checks, Instant and Delayed modes, tick-based CPS cooldown and target-state cleanup were corrected.
  • Module audits and conflict groups were added for Speed variants, AutoMLG/WaterBucket and AnchorMacro/CrystalMacro.
  • IntegrityMode can disable modules conflicting with an active server-rule profile. It does not attempt server-detection avoidance.
  • Preserved config backup, validation, import/export and recovery paths.
  • Also corrected GuiModule re-entry, Velocity state handling, AutoSoup null handling, AutoRefill string comparison, CustomFOV restore and BlockHit state handling.

Validation reported

  • gradlew clean compileJava test build completed with exit code 0 using JDK 8 (Temurin 8u482) and Gradle 4.7.
  • Dependency-free self-check: 53 passed, 0 failed. Gradle test is wired to selfCheck; there are no JUnit test sources in the offline tree.
  • Release JAR contained the new GUI, chooser, config screen, description table and new module classes.
  • Minecraft itself was not launched, so runtime behaviour remained unverified.
Not delivered: Fabric 26.3 port and a single Forge/Fabric multi-version JAR. Anti-cheat evasion, stealth and detection bypass were not implemented.
